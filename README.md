# Cyberfate · 数字命理观星台

一个以开源算法为底座、以现实观测与复盘为核心的中文命理产品。复杂盘面作为可追溯证据存在，普通用户先从“自己、时间、关系”三个现实问题进入。

完整的产品功能、技术架构、规则口径、理论边界与参考来源见 [产品与技术设计文档](./docs/DESIGN.md)。

## 已实现

- 任务式首次体验：先选择自己、阶段或关系议题，再填写资料
- 城市快捷输入、手动经度与未知时辰模式；未知时辰只展示三柱有限观察
- 真太阳时校正：经度时差 + 均时差
- 紫微斗数：十二宫、主辅杂曜、亮度/四化、命身主、五行局、大限区间
- 子平八字：四柱、藏干、十神、纳音、十二长生、命宫、身宫、胎元、旬空
- 双盘总览与五层证据导读：结论、盘面依据、替代解释、未纳入因素、专业入口
- 三条核心观察、现实核对问题与一键加入观测簿
- 观测簿：过去经历回填、符合 / 反例 / 不确定状态、自由笔记、阶段摘要、复盘日期与日历提醒导出
- 桌面完整盘面与移动端逐柱 / 逐宫阅读模式
- 单人姻缘：夫妻宫、配偶星、桃花、合冲、紫微夫妻宫与未来五年窗口；每条结论均附替代解释、局限和现实核对问题
- 时运六象：连续六年流年取象，输出得时乘势、守正慎行、动象已彰、气弱待时、吉凶相参、象静无征，并保留逐条计算依据
- 关系复盘：未来五年可逐年标记实际经历、补充本地笔记并随时清除
- 双人合盘：吸引、沟通、冲突、长期结构、时间协调五个可解释维度；支持对方时辰未知的有限比较和脱敏摘要复制
- 八字、紫微、关系三套上下文术语词典，桌面分栏、移动端逐项展开
- 全局可读性基线：正文 13–15px、辅助标签不低于 11px，并提高深色背景上的弱文字对比度
- 浏览器本地档案、隐私友好的本地事件计数、二次确认删除与清空、命盘导出，以及全部档案与观测的备份恢复
- 可见算法版本与固定命例回归检查
- 桌面端与移动端响应式界面

所有出生资料均在浏览器内计算；应用没有数据库，也不会主动上传个人资料。

## 技术栈

- Next.js 16 / React 19 / TypeScript
- [iztro](https://github.com/SylarLong/iztro)：紫微斗数排盘
- [lunar-javascript](https://github.com/6tail/lunar-javascript)：历法与八字排盘
- 原生 CSS：数字观星台视觉系统

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的本地地址（通常是 `http://localhost:3000`）。

生产验证：

```bash
npm run typecheck
npm run verify:charts
npm run build
npm start
```

## 计算约定

- 当前仅支持按中国标准时间（UTC+8）记录的出生时间，真太阳时以东经 120° 为基准；海外时区暂不适用。
- 均时差使用常见近似公式，结果显示到分钟。
- 八字按节气分月，晚子时采用 lunar-javascript 的 sect 2 规则。
- 紫微本命盘使用 iztro 的通行算法与 `fixLeap=true`。
- 紫微干支日期与八字四柱可能因年界、月界规则不同而呈现差异，这是两套术数体系的计算口径差异，并非数据覆盖。

## 产品边界

- 当前版本专注“生成观察 → 留下问题 → 记录经历 → 回来复盘”，不继续扩张六爻、奇门和风水门类。
- 云同步、付费深报与跨设备档案需要独立的服务端、加密和合规设计，当前界面不放置无法兑现的入口。
- 不提供开放式“AI 大师”，不使用恐吓式通知，也不以单一分数评价关系。
